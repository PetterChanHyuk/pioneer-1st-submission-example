# 2주차 과제 안내 · 국내상품 전략 구현

> 운영진이 참가팀에 전달하는 과제 안내문의 **예시**입니다. 실제 과제 문구·평가 기준은 운영 공지를 따릅니다.

**제출일: 2026/10/30(금)** · 마감 시각 미정(추후 공지)
**활동 기간:** 2026/10/24(토) ~ 2026/10/30(금)

## 1. 목표

NH선물 Open API 로 **국내 선물·옵션 상품 하나**에 대한 규칙 기반 전략을 구현하고, 실제로 실행한 기록을 근거로 결과를 분석합니다.
수익률 자체는 평가 기준이 아닙니다. 전략이 설계대로 동작했는지, API 를 올바르게 썼는지, 결과를 근거와 함께 해석했는지를 봅니다.

## 2. 상품 범위

- NH선물 Open API 로 조회·주문할 수 있는 **국내 선물 또는 옵션** 중 1개 종목 이상.
  예: 코스피200 선물, 미니코스피200 선물, 코스닥150 선물, 3년국채 선물, 미국달러 선물, 주식선물 등.
- 월물을 명시합니다. 실행 중 만기가 가까운 월물은 피하거나, 만기 처리 방식을 보고서에 적습니다.

## 3. 필수 기능

1. **시세 수신** — REST 조회(현재가·분봉 등) 또는 WebSocket 실시간 수신 중 하나 이상으로 판정에 쓸 가격을 받습니다.
2. **신호 판정** — 진입·청산 조건을 코드나 설정으로 명확히 정의합니다. 조건과 임계값을 보고서에 적습니다.
3. **주문 또는 주문 의도 기록** — 모의계좌 주문, 또는 주문을 내지 않는 시뮬레이션 중 하나로 신호를 처리합니다.
   어느 쪽인지 반드시 구분해 적습니다.
4. **위험 관리 한 가지 이상** — 손절, 일일 손실 한도, 최대 보유 수량, 세션 끝 정리 중 하나 이상.
5. **실행 기록** — 실행 식별자, 시각, 환경(모의/실전/시뮬레이션), 종목, 설정값과 신호·주문·체결·오류를 파일로 남깁니다.

## 4. 선택 기능

- 지난 데이터로 같은 규칙을 돌려 보는 백테스트와, 실행 결과와의 비교
- 주야간 세션을 나눈 실행
- 미체결·부분체결·거부·취소 처리
- 호출 제한(초당 호출 수) 대응과 재연결 처리
- 결과 요약을 자동으로 만드는 스크립트

## 5. 테스트

- **실전 계좌 주문은 하지 않습니다.** 모의계좌 또는 앱 내부 시뮬레이션으로 검증합니다.
- 시장·시스템 사정으로 모의거래가 어려우면 검증·분석·기능 구현 결과로 대체할 수 있습니다. 대체했다면 그 사실과 까닭을 적습니다.
- 정규 거래시간 중 최소 한 세션 이상 실제로 실행하고, 실행 시작·종료 시각을 기록합니다.
- 시뮬레이션 체결은 모의계좌의 실제 체결로 표현하지 않습니다. 주문 접수만 있고 체결 확인이 없으면 체결 성공으로 적지 않습니다.
- 실제로 발생한 오류는 오류코드·메시지·재현 조건과 함께 남깁니다.

## 7. 평가 기준

> 아래 배점 구조는 운영기획안의 **예시**이며 확정된 정책이 아닙니다. 확정 기준은 운영 공지를 따릅니다.

| 관점 | 확인하는 것 |
| --- | --- |
| 전략 실행 | 설계한 조건대로 신호가 나고, 그 근거가 기록에 남았는가 |
| API 작동 | 사용한 API 를 명세에 맞게 호출했고, 응답·오류를 처리했는가 |
| 결과 분석 | 실제 수치로 결과를 해석하고 한계를 밝혔는가 (손실 결과도 분석 대상) |
| 오류·개선 | 실제 겪은 오류와 개선 방향을 구체적으로 적었는가 |
| 재현성 | 다른 사람이 README 만 보고 같은 실행을 재현할 수 있는가 |

- 기획안 예시: 전체 평가는 정량 80%·정성 20%이며, 정량 안에서 주차별 과제가 50점(예시)을 차지합니다.
- 기획안 예시: 오류 제보는 기본 점수와 별도의 가점으로 다룹니다. 상한과 중복 기준은 아직 정해지지 않았습니다.
