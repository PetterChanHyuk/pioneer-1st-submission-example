# NH선물 REST API Pioneer 1기 · 제출 예시

발대식에서 팀 GitHub 저장소 구성과 주차별 결과물 정리 방법을 보여주는 **운영 담당자의 예시 저장소**입니다.
참가팀 공용 제출함이 아닙니다. 각 팀은 자신의 저장소를 만들고 회사 Discord에 링크를 전달합니다.

**활동 기간:** 2026.10.21 ~ 2026.12.11  
**과제 제출:** 매주 금요일까지 · 마감 시각은 추후 안내

## 1주차에 할 일

1. 팀 GitHub 저장소를 생성합니다.
2. README에 팀명, 프로젝트 소개, 주차별 결과물 위치를 적습니다.
3. 운영진이 링크를 통해 저장소를 확인할 수 있도록 접근 상태를 확인합니다.
4. **10/23(금)까지 회사 Discord에 팀 저장소 링크를 전달합니다.**

1주차 제출 범위는 저장소 링크까지입니다. 프로그램·보고서·실행 결과 제출은 요구하지 않습니다.
이 저장소의 폴더와 문서는 편의를 위한 예시이며, 첫 주에 모든 폴더를 만들 의무는 없습니다.
팀 저장소의 공개/비공개 기준과 운영진 초대 계정은 별도 공지를 따릅니다.

## 2주차부터 결과물을 정리하는 방법

각 주차의 README에서 다음 자료를 찾을 수 있게 연결합니다.

- 소스코드와 설치·실행 방법
- 과제 목표, 대상 상품, 전략과 매매 로직, 사용 API
- 실제 실행환경·기간·조건과 결과 근거
- 결과 분석, 한계, 오류 및 개선사항

보고서는 README에 통합하거나 별도 파일로 작성해 링크할 수 있습니다.
[보고서 작성 틀](templates/report-template.md)을 참고하세요. 실제 수행하지 않은 결과는 적지 않습니다.

## 현재 예시의 상태

- 1주차 저장소 구성 안내와 주차별 문서 틀을 준비했습니다.
- **2주차 제출 예시를 채웠습니다.** 과제 안내·전략 설정·기록 요약 스크립트·백테스트와 앱 시뮬레이션 실행 근거·보고서를 [week02](week02/README.md)에 담았습니다. 앱 시뮬레이션이라 계좌 주문은 없습니다. 국내 주간 실행 결과는 장 마감 뒤 확정해 보고서에 채웁니다.
- 나머지 주차도 제출 위치를 보여주는 안내만 있으며, 완료된 과제로 표시하지 않습니다.

## 기록 시 주의사항

- APP Key, Secret Key, 토큰, 계좌 비밀번호와 개인 설정 파일은 올리지 않습니다.
- 화면과 로그의 계좌 식별정보·개인정보를 확인하고 필요한 부분을 가립니다.
- 앱 내부 시뮬레이션, 모의계좌 주문, 실전 기록을 구분합니다.
- 주문 접수와 실제 체결을 구분하고, 실행하지 않은 수치나 성공 여부를 만들지 않습니다.
